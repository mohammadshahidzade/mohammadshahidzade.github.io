01 / CONTEXT

From a soft processor to an application-class research platform.

CVA5 is a highly configurable RISC-V processor designed for FPGA implementations. Its extensible execution structure makes it a strong foundation for architecture research, but running a full operating system requires far more than a working instruction pipeline.

The project added the processor and SoC features needed to support Linux, creating the baseline used by MEERKAT and later accelerator-aware operating-system research.

02 / MY WORK

Closing the gap between RTL and a Linux prompt.

CVA5 RTLPrivilege + VMPLIC / CLINTOpenSBILinux
  • Designed and integrated PLIC and CLINT hardware for external, timer, and software interrupts.
  • Added and debugged privilege-mode behavior, control/status register paths, and instruction sequences needed by the kernel and firmware.
  • Integrated virtual-memory support, address translation, and the system infrastructure around the core.
  • Used Verilator and FPGA execution to diagnose failures across the processor, boot firmware, device tree, and Linux kernel.
  • Connected the core into LiteX-based SoCs for repeatable system generation and hardware evaluation.
03 / WHY IT MATTERS

Linux support enables system-level architecture research.

Booting Linux transformed CVA5 from a processor RTL project into a platform for studying real software behavior. It enabled later work on shared virtual memory, interrupt policy, accelerator invocation, and heterogeneous scheduling—questions that cannot be answered by isolated accelerator simulation alone.

The linked FCCM workshop material introduces CVA5’s architecture and extensibility; the public OpenHW repository contains the upstream core.
